# DBMS Practical

## Overview

This repository contains the SQL practical work for the Database Management
Systems course.

The practical demonstrates database creation, table design, constraints,
sample data, SQL queries, and basic database administration commands.

## Database

Database name:

college

## Tables

The database contains the following tables:

- STUDENT
- COURSE
- SOCIETY
- ADMISSION
- ENROLLMENT

## Project Files

### 01_DDL.sql
Contains:
- Database creation
- Table creation
- Primary keys
- Foreign keys
- Unique constraints
- Check constraints
- Referential actions

### 02_Sample_Data.sql
Contains the sample data inserted into the database.

### 03_Queries.sql
Contains the 25 prescribed SQL queries.

### 04_DBA_Commands.sql
Contains database administration commands including:
- User creation
- Role creation
- GRANT
- REVOKE
- Index creation
